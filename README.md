# «الباحث في السنة» (Al-Bahith fi Al-Sunnah) — المرجع الشامل للسنة النبوية

منصة ويب تفاعلية حديثة، سريعة، ومجانية ١٠٠٪، مبنية بتقنية **Next.js 15 (Static HTML Export)** مع دعم كامل لاتجاه الكتابة العربي من اليمين إلى اليسار (**RTL-First**)، ومصممة بأحدث معايير تجربة المستخدم على الهواتف والأجهزة المكتبية.

---

## 🌟 مميزات وأقسام المنصة

1. **الأحاديث النبوية المشروحة (`/hadiths`)**:
   - أكثر من ٥٣٠ حديثاً نبوياً صحيحاً وحسناً منقولاً بأمانة علمية تامة من **موسوعة الأحاديث النبوية (`HadeethEnc.com` — تابعة لـ IslamHouse.com)**.
   - تشمل: المتن المضبوط بالشكل، الدرجة والتخريج، الشرح الميسر، الفوائد التربوية المرقّمة، ومعاني الكلمات الغريبة.
   - ميزة حفظ الأحاديث في المفضلة محليًا (`localStorage`).

2. **أذكار وأدعية حصن المسلم (`/adhkar`)**:
   - جميع أبواب كتاب «حصن المسلم من أذكار الكتاب والسنة» للشيخ د. سعيد بن وهف القحطاني رحمه الله.
   - عدّاد تسبيح تفاعلي بالاهتزاز وحفظ التقدم اليومي تلقائيًا.

3. **الأربعون النووية مع التسميع الذاتي (`/nawawi40`)**:
   - اثنان وأربعون حديثاً جامعاً للإمام النووي رحمه الله.
   - خاصية إخفاء المتن للتسميع الذاتي ورصد الحفظ الفردي.

4. **السيرة النبوية العطرة (`/seerah`)**:
   - ثلاثون محطة تاريخية متسلسلة مستندة لكتاب «الرحيق المختوم» للمباركفوري رحمه الله.
   - تغطي المراحل الكبرى من المولد الشريف حتى الرفيق الأعلى مع الشواهد القرآنية والدروس التربوية.

5. **متتبع سنن اليوم والليلة (`/daily-tracker`)**:
   - جدول تفاعلي يرصد سنن الاستيقاظ والصلوات والتعاملات اليومية والنوم.

6. **قسم تثبّت للأحاديث المنتشرة التي لا تصح (`/verify`)**:
   - بيان الأحاديث الضعيفة والباطلة المشتهرة على ألسنة الناس مع البديل الصحيح الثابت وتخريجه من **الدرر السنية**.

7. **محرك البحث الذكي والتوسيع الدلالي (`/search`)**:
   - بحث فوري بدون سيرفر أو استهلاك ذكاء اصطناعي مكلف (Zero API Runtime).
   - يفهم أكثر من ٦٥ حالة نفسية وحياتية بالعامية المصرية والخليجية والشامية والفصحى (مثل: «مخنوق وحزين»، «عندي دين وعايز رزق»، «مشاكل مع مراتي»، «كابوس في النوم»، «متعصب واتخانقت»).
   - يعرض تلقائيًا في شاشة واحدة: **أقرب حديث نبوي بشرحه وفوائده + أقرب ذكر مأثور من حصن المسلم**.

8. **مولّد بطاقات المشاركة لواتساب ومنصات التواصل (`ShareCardModal`)**:
   - توليد بطاقات صور رقمية عالية الدقة (PNG) تعمل ١٠٠٪ داخل المتصفح بتقنية Canvas بالقوالب الورقية والداكنة والكريمية بأبعاد مربعة أو طولية (Story).

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Static HTML Export `output: 'export'`)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/) مع استخدام صارم للخصائص المنطقية (`ms-`, `me-`, `ps-`, `pe-`, `border-s-`, `text-start`, `text-end`)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State & Storage**: Client-side State + Browser `localStorage` (100% Offline & Free)
- **Deployment**: جاهز للنشر المباشر والمجاني على [Vercel](https://vercel.com/) و[GitHub Pages](https://pages.github.com/).

## 🌐 خطوات الرفع على GitHub والنشر على Vercel

### الخطوة الأولى: الرفع على مستودع GitHub
1. أنشئ مستودعاً جديداً (New Repository) فارغاً على حسابك في GitHub (مثلاً باسم: `sunnah-platform`).
2. افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:

```bash
git init
git add .
git commit -m "الإصدار الأول: إطلاق الباحث في السنة"
git branch -M main
git remote add origin https://github.com/USERNAME/sunnah-platform.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك على GitHub)*

---

### الخطوة الثانية: النشر على Vercel بنقرة واحدة
1. توجّه إلى [Vercel Dashboard](https://vercel.com/dashboard) وسجّل دخولك بحساب GitHub.
2. اضغط على **"Add New..."** ثم اختر **"Project"**.
3. اختر المستودع `sunnah-platform` من القائمة واضغط **"Import"**.
4. سيتعرّف Vercel تلقائيًا على Next.js وإعدادات البناء:
   - **Framework Preset**: `Next.js`
   - **Build Command**: `npm run build`
   - **Output Directory**: `out` (أو التلقائي)
5. اضغط **"Deploy"**.
6. خلال دقيقة واحدة سيعطيك Vercel رابط النطاق الحي المجاني (مثل: `https://sunnah-platform.vercel.app`) مع شهادة SSL مجانية وتحديث تلقائي مع كل `git push`!
